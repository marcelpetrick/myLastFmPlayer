myLastFmPlayer Documentation
============================

``myLastFmPlayer`` is a maintained, fully usable Linux desktop application for
turning a user's public Last.fm loved tracks into a persistent local music
library. It resolves tracks through YouTube search, downloads audio files, and
plays and optionally scrobbles them through its PyQt interface.

Start with :doc:`architecture` for the runtime flow and diagrams. Use
:doc:`api` for class and function reference pages generated from the Python
source.
